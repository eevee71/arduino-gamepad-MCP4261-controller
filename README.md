# Arduino and MCP4261 Digital Potentiometer Control with Wireless Gamepad Controller
📖 Overview

The Arduino reads input from a 2.4 GHz wireless gamepad (Joy-it SBC-WL-Controller) and uses it to set the wiper values of an MCP4261 digital potentiometer.
Joystick movement directly adjust the voltage on the MCP4261, allowing real-time control of an external circuit.

🔌 Setup

• MCP4261 connected to Arduino via SPI 
• Wireless controller receiver connected to Arduino digital pins 
• Common VCC and GND for Arduino, MCP4261, and the receiver module
